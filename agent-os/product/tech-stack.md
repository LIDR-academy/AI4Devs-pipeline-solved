# Tech Stack

## Frontend

- **React**: Core UI library.
- **Languages**: TypeScript (`.tsx`) and legacy JavaScript (`.js`).
- **Styling**: React Bootstrap.
- **Routing**: React Router (`react-router-dom`).
- **HTTP Client**: Axios.

## Backend

- **Node.js**: Server runtime.
- **Framework**: Express.
- **Language**: TypeScript (`.ts`).

## Database

- **PostgreSQL**: Relational database storage.
- **ORM**: Prisma ORM.

## CI/CD & Deployment

- **CI/CD**: GitHub Actions workflows.
- **Artifacts**: AWS S3 storage.
- **Web Server / Proxy**: Nginx.
- **Process Manager**: PM2.
- **OS Platform**: EC2 Linux instances.
